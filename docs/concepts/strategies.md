# Стратегии

**Стратегия** определяет, *как* флаг применяется на конкретном окружении. Каждый флаг может иметь разные настройки стратегий для разных окружений.

## Конфигурация стратегии

| Компонент | Описание |
|-----------|----------|
| **Состояние** | Включён или выключен флаг на этом окружении |
| **Контекст** | Набор атрибутных правил (constraints) для таргетинга |
| **Сегменты** | Переиспользуемые группы пользователей (ИЛИ-логика) |
| **Процент** | Детерминированный хеш-роллаут (0-100) |

## Как работают стратегии

Оценка стратегии происходит в фиксированном порядке:

1. **Проверка состояния** — если выключен, вернуть `false`
2. **Проверка контекстных правил** — все правила должны совпасть (логическое И)
3. **Проверка сегментов** — хотя бы один сегмент должен совпасть (логическое ИЛИ)
4. **Если есть и правила, и сегменты** — достаточно совпадения одного
5. **Процентный роллаут** — MurmurHash32 от `flagKey + userId`, сравнение с процентом
6. **По умолчанию** — если ничего не совпало, вернуть `false`

## Таргетинг через контекстные правила

Правила сопоставляют атрибуты пользователя с помощью операторов:

```json
{
  "constraints": [
    {"field": "country", "operator": "in", "values": ["RU", "BY", "KZ"]},
    {"field": "plan", "operator": "eq", "values": ["premium"]}
  ]
}
```

Все правила должны выполниться (логическое И). Если атрибут отсутствует в контексте, правило возвращает `false`.

## Таргетинг через сегменты

Сегменты — переиспользуемые группы, задаваемые отдельно и подключаемые по ссылке. Стратегия может ссылаться на несколько сегментов — достаточно совпадения с любым (логическое ИЛИ).

## Процентный роллаут

Детерминированное распределение через хеширование:

```
hash = MurmurHash32(flagKey + userId) % 100
if hash < percentage → enabled
else → disabled
```

Если `userId` отсутствует, используется `sessionId`.

## Стратегии по окружениям

Стратегии настраиваются для каждого окружения отдельно:

| Окружение | Стратегия |
|-----------|-----------|
| **dev** | 100% роллаут, без правил — все разработчики видят фичу |
| **staging** | 50% роллаут + сегмент `beta: true` — часть пользователей staging |
| **production** | 10% роллаут + правила по стране — постепенный глобальный запуск |

Каждое окружение имеет свой API-ключ. SDK получает только стратегию для своего окружения.
